# CarePoint - Hospital Management System

A responsive beginner-friendly hospital management web application built with HTML, CSS and JavaScript.

## Features
- Dashboard with patient, doctor, appointment and revenue summaries
- Patient management (add, edit, delete, search)
- Doctor management (add, edit, delete, search)
- Appointment scheduling and status tracking
- Billing and payment status management
- Browser localStorage persistence
- Responsive layout for desktop and mobile

## How to run
1. Extract `HospitalManagementSystem.zip`.
2. Open the extracted `HospitalManagementSystem` folder.
3. Double-click `index.html` to open it in Chrome, Edge or Firefox.

No installation or database setup is required. Data is stored in the browser's localStorage on the device/browser where the app is opened.

## Files
- `index.html` - application structure
- `style.css` - design and responsive styling
- `script.js` - application logic and localStorage
